Assume it takes a machine:

    62 ns to read a word from either instruction or data memory
    54 ns to read or write up to 2 registers in the register file
    58 ns to perform an ALU operation

How many nanoseconds would the clock period be using the single cycle design?
(Remember that incrementing the PC is done at the same time as reading the instruction,
so the time to increment the PC does not need to be counted)
 
 
 
How many nanoseconds long would the clock period be using the multi-cycle design?
 
View Feedback

Single cycle is the length of the longest instruction (lw):
62 ns to read the instruction from memory
+ 54 ns to read the base register value
+ 58 ns to compute data address in the ALU (add base register value to immediate value)
+ 62 ns to read the data from memory
+ 54 ns to write the data to the register

Multi-cycle is the length of the longest step (reading from memory)
