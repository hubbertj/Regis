Ch 1.6 Table 2: universal instantiation: all people have brains, therefore this one person has a brain

c is always one example of the full set (x). P(x) in some function or property true for x, and P(c) is some function or property is true for one element of x, which we call c.

Universal involves all x (the upside down A), and existential involves one x (the backwards E). Generalization goes from one example (c) to a set (x), and instantiation goes from the set (x) to one example (c).

  • proofs

contraposition: basically using Modus Tollens

contradiction: take something we're trying to prove and negate it, then show that results in a contradiction. Remember a contradiction is q ^ ¬q, so it can never be true. The opposite of a tautology.

Example: there is not a smallest rational number r

  1. negate it: there is a smallest rational number r (call this ¬p)
  2. ¬p → q (q is that r in the smallest rational number)
  3. provide another example that shows ¬q: r/2 is still a rational number, but is smaller than r; therefore ¬q
  4. we have a contradiction (q ^ ¬q), therefore ¬p is false and p is true

Cardinality Ch 2.1 definition 4

Cardinality is the count of unique items in a set.

Example: cardinality of {a, {a, a}} is 2. The two elements are a and {a, a}, which are different elements even though they both contain a. The cardinality of {a, a} is 1, because it only contains one element, a. Does the empty set count as as element? Yes.

Week 4: Big O, pseudocode, algorithms

  • big-O

remember for click-and-drag type problems, therefore is usually last, 'suppose' or 'consider' are usually first

Remember the trick of doing something like:

x^5 < C(x^3 + 50*x^2 + 1000*x + 10)

can be written as

x^5 < C(x^3 + x^3 + x^3 + x^3) = 4C(x^3)

because 50*x^2 < x^3, and the same for the the other lower powers of x (10 is just 10*x^0)

A trick to get the big-O of factored functions is to find the biggest element in each group. Example:

(n^2 + 1)(log(n) + n)

The biggest elements are n^2 and n, so multiply these two to get n^3; which is the order of the overall function. Remember you can also plot things on wolframalpha.com

  • pseudocode

definitions in appendix 3

For any types of 'identify minimum number of assignment statements' type problems, write out the pseudocode. For example, how many assignment statements needed to swap (x, y) with (y, x)?

To do a swap, we need to set a temporary variable while we replace one variable with another.

procedure swap(x, y: integers)


temp := y


y := x


x := temp

So for this one, we need 3 assignment statements.

Another tip: Run through code with an example value to test it. If you're having trouble keeping track in your head, write things down.

For example, if we have a procedure to find the max of a list of integers:

procedure findmax(a1, a2, a3...an: integers)


max := a1


for i := 2 to n


  if ai > max then


    max := ai

Try this with the list [1, 5, 7, 3, 1] to make sure it works.
